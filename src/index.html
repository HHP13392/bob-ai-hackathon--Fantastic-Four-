function getRiskStatus(score: number) { if (score >= 80) return "Critical"; if (score >= 60) return "High"; if (score >= 30) return "Medium"; return "Low"; } function getRecommendation(asset: Asset) { if (asset.riskScore >= 80) return "Inspect immediately. Pre-position a crew."; if (asset.riskScore >= 60) return "Schedule inspection within 12 hours."; if (asset.riskScore >= 30) return "Inspect during next cycle."; return "Continue normal maintenance."; }

About GridGuard

Architecture, team structure, and tRPC integration overview.

GridGuard is a predictive grid resilience platform that ingests sensor telemetry, weather forecasts, and maintenance history to produce per-asset risk scores in real time. Operators shift from reactive to preventive maintenance — cutting outage duration, protecting revenue, and keeping customers connected.
